For this assignment, we were instructed to select a song and find or write Arduino code to play that song when a button is pressed. I selected *Für Elise in A Minor* by Ludwig van Beethoven. I selected this song for two reasons: 1) I remembered learning it on piano as a kid and I know the beginning of it well enough that I'd be able to tell when I messed something up, and 2) it is in the public domain, so I could find free sheet music for it on [Musecore](https://musescore.com/classicman/fur-elise?srsltid=AYCX9vJ-Oq018CYNJhA_y0eU9UfRMDoi40QtYsMUttTse4_J788vAb1u). 

To make this code play in a loop on my Arduino, I had to put all my code in the main loop, with 3 main parts:
1. reading in the button value
2. a conditional that plays the song if the button is pressed
3. an extra delay
Within the if statement, I had to write two lines of code for each note played: playing the buzzer at the correct tone, and a delay for the correct amount of time. I added comments when each measure started and a new line after each rest in the music to make it easier to follow the notes. 

Though choosing this song certainly made my job relatively easy (I only had to add a couple notes outside of the ones already defined in the in-class example, and it was only 8 measures of music, 2-3 of which are repetition), next time I might want to choose a different song that would make the assignment more of a challenge and more fun. 
I also made some silly errors setting up my button (i.e. trying to write "if (BTN_PIN) ..." instead of reading in the button, but those were resolved pretty quickly once referring to my past code.
